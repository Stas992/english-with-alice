# English with Alice

Локальный учебный сайт для курса английского языка на 16 недель.

## Публикация через GitHub Pages

В репозитории уже настроена автоматическая публикация. После отправки файлов в ветку `main` GitHub Actions разместит сайт.

1. На GitHub создайте пустой репозиторий, например `english-with-alice`.
2. Загрузите содержимое этой папки в корень репозитория и отправьте его в ветку `main`.
3. В репозитории откройте **Settings → Pages** и выберите **GitHub Actions** как источник публикации.
4. Во вкладке **Actions** дождитесь успешного задания **Publish course site**. Адрес сайта появится в **Settings → Pages**.

GitHub Pages делает сайт доступным в интернете. Прогресс курса сохраняется в браузере на конкретном компьютере и автоматически между компьютерами не переносится.
